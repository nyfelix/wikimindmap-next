Kinds: the same six branches on every map

Branches no longer follow the article’s chapters. Every linked article is sorted by what it is, according to Wikidata: a person, an organization, a work, a concept, an event or a place. The branches always sit in the same spot, so readers learn where to look. Dot size shows how many people read that article each month.

Sample data

How a link gets its branch

    The app reads the Wikidata “instance of” value of each linked article and walks up its parent classes until one of these six matches. Anything unmatched goes to Concepts.

    What this lens is good at

    • Answers “who and what is connected to this?” at a glance
    • Every map has the same shape, so it can be learned
    • Empty branches carry meaning too: no places, no events
    • Needs no AI, only Wikidata and page views

    Weak spots to judge

    • Concepts gets crowded on abstract topics; it may need its own split, for example methods vs. fields
    • The link to the article’s own text is lost; the preview card has to show where the link appears
    • Some Wikidata types are odd or missing and need a hand-made mapping

    Titles are real Wikipedia articles. Kinds, “instance of” values, view counts and link directions are illustrative sample data in assets/sample-data.js. Tap a label for a preview, tap ⊕ to make it the center. Bold labels have sample data behind them.
